Optimizing Editorial Allocation: Machine-Learned Decision Support for Search Content Decay

M. Rohaan Zahid · ML Engineering Intern · FlyRank Track
Abstract: Maintaining organic search performance across enterprise web properties requires prioritizing content refreshes before engagement severely decays. In this study, we evaluate whether gradient-boosted decision trees trained on rolling search metrics can outrank traditional heuristic rules. Evaluating models across client-grouped validation splits, we observed an NDCG@10 lift of +0.094 over baseline scoring rules. These results translate directly into an actionable editorial playbook with strict reason codes. The methodology demonstrates that machine learning provides measurable decision support for content lifecycle triage while highlighting areas requiring human oversight.

1. Introduction & Problem Statement

Content aging in search engine results pages (SERPs) follows non-linear decay dynamics. Manual editorial triage across thousands of URLs is operationally inefficient. This project designs, evaluates, and audits a supervised decision-support pipeline that ranks decay risk and assigns structured reason codes to queue high-priority pages for editorial review.

2. Data & Sanitization

This work evaluates features extracted from production-scale search performance datasets. To ensure public safety and data integrity:

  • All client names, actual domains, and query strings are anonymized and hashed.
  • Features include rolling 90-day pre-intervention aggregates: historical_ctr, serp_position, staleness_days, and term_overlap_score.
  • Low-volume tail queries (<5 lifetime impressions) were excluded to prevent sparse noise.

3. Methodology & Validation Design

To prevent target and group leakage, we implemented a strict Grouped Split (60/20/20) partitioned on client domain and query cluster IDs. No URLs from evaluated domains in the test split were present during training. All feature windows strictly precede the evaluation target date.

4. Results vs. Baseline

All candidate models were evaluated on the identical held-out test split against the Week-4 rule-based heuristic:

Model Validation Split Accuracy NDCG@10 Lift vs Baseline
Week-4 Baseline Heuristic Grouped (Domain-Level) 65.0% 0.420 —
Logistic Regression Grouped (Domain-Level) 68.2% 0.453 +0.033
Random Forest Grouped (Domain-Level) 71.4% 0.485 +0.065
XGBoost (LambdaMART) Grouped (Domain-Level) 73.1% 0.514 +0.094

XGBoost provided the strongest ranking metric, confirming that tree ensembles effectively resolve non-monotonic decay signals.

5. Limitations & Honest Claim Boundaries

  • Directional Decision Support: Predictions reflect historical statistical correlation, not direct causal drivers of search traffic.
  • External SERP Volatility: Unobserved search engine core algorithm updates and competitor activity fall outside the model scope.
  • Tail Asset Uncertainty: Cold-start documents with low historical volume retain higher prediction variance.

6. Ranked Action Playbook

  • COMPREHENSIVE_REFRESH: High model risk score combined with staleness >180 days.
  • TITLE_CTR_OPTIMIZE: Top 15 SERP position with below-average CTR conversion.
  • CONSOLIDATE_OR_PRUNE: Persistent low impression volume on aging content assets.
  • Strict No-Go Automation List: Automated document deletion, algorithmic URL pruning, and unreviewed bulk 301 redirects are prohibited.
